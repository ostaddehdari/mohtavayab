# Design System راست‌چین هادی

## زبان بصری

رابط از مفهوم «اتاق فرمان محتوای چندشبکه‌ای» الهام می‌گیرد: زمینهٔ سرمه‌ای عمیق، سیان برای عملیات و دادهٔ زنده، بنفش برای هوش مصنوعی، سبز برای موفقیت، کهربایی برای انتظار و رز برای خطا. فونت اصلی **Vazirmatn Variable** و آیکون‌ها **Font Awesome** هستند.

## اجزای پایه

پکیج `@mohtavayab/ui` توکن‌های CSS و چهار جزء نخست `Surface`، `MetricCard`، `StatusBadge` و `Skeleton` را عرضه می‌کند. توکن‌ها در `packages/ui/src/tokens.css` و قرارداد مستقل آن‌ها در `design/tokens.json` قرار دارد.

| حوزه     | قاعده                                             |
| -------- | ------------------------------------------------- |
| فاصله    | شبکهٔ ۴ پیکسلی                                    |
| گوشه‌ها  | ۱۰، ۱۶، ۲۴ و ۳۲ پیکسل                             |
| فوکوس    | حلقهٔ سیان ۳ پیکسل با Offset                      |
| متن عادی | نسبت کنتراست حداقل ۴٫۵:۱                          |
| وضعیت    | رنگ همراه متن/آیکون؛ رنگ به‌تنهایی حامل معنا نیست |
| لمس      | هدف تعاملی ترجیحاً حداقل ۴۴ پیکسل                 |

توکن‌های منطقی RTL به جای `left/right` برای فاصله و چیدمان اجزای قابل‌استفادهٔ مجدد ترجیح دارند. مقادیر عددی یا شناسه‌ها می‌توانند `dir="auto"` یا `ltr` داشته باشند.
