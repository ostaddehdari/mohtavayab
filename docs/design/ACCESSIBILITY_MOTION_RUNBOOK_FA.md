# راهنمای دسترس‌پذیری و حرکت

## نقش موتورهای حرکت

| موتور                | محل استفاده     | سیاست بارگذاری                 | Reduced Motion              |
| -------------------- | --------------- | ------------------------------ | --------------------------- |
| Motion               | پوسته و داشبورد | پایه                           | Fade یا بدون جابه‌جایی شدید |
| GSAP + ScrollTrigger | روایت Landing   | Dynamic import                 | غیرفعال                     |
| Lenis                | اسکرول Landing  | Dynamic import                 | غیرفعال                     |
| Three.js             | گراف Hero       | Dynamic import، ۳۰fps، DPR 1.5 | تصویر ثابت                  |
| Rive                 | کارت انتقال     | Dynamic import و فایل محلی     | نمای ثابت منبع/مقصد         |

Three.js هنگام خروج عنصر از Viewport یا پنهان‌شدن Tab متوقف می‌شود. حرکت پیوسته در داشبورد ممنوع است. هیچ داده یا عملیاتی فقط از راه انیمیشن قابل فهم نیست. قرارداد بودجه در `design/motion-budget.json` است.

## چک‌لیست پذیرش

- ترتیب Tab از راست به چپ و منطقی باشد؛
- Skip link و یک `main` قابل شناسایی وجود داشته باشد؛
- دکمه‌های آیکونی نام دسترس‌پذیر داشته باشند؛
- نمودار خلاصهٔ متنی/ARIA داشته باشد؛
- در ۳۲۰، ۶۸۰، ۱۱۲۰ و ۱۴۴۰ پیکسل شکست چیدمان رخ ندهد؛
- آزمون axe بدون تخلف خودکار اجرا شود؛
- `prefers-reduced-motion` در CSS و تمام موتورهای JS رعایت شود.
