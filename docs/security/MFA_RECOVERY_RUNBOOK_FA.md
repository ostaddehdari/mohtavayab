# Runbook احراز دومرحله‌ای و بازیابی

## فعال‌سازی TOTP

کاربر باید نشست معتبر و CSRF Token داشته باشد. API یک راز ۱۶۰ بیتی و QR موقت ده‌دقیقه‌ای می‌سازد. روش MFA تنها پس از ارائهٔ کد معتبر فعال می‌شود. پنجرهٔ پذیرش حداکثر یک بازهٔ ۳۰ثانیه‌ای در دو سوی زمان جاری است.

پس از تأیید، ده کد بازیابی ۶۴ بیتی فقط یک‌بار نمایش داده می‌شوند. نسخهٔ Argon2id آن‌ها ذخیره و هر کد پس از استفاده حذف می‌شود. فعال‌شدن MFA همه نشست‌های موجود را لغو می‌کند.

## چالش ورود

- عمر چالش: ۵ دقیقه؛
- حداکثر تلاش: ۵ بار؛
- کد TOTP یا Recovery Code یک‌بارمصرف؛
- کد و راز هرگز Log نمی‌شوند؛
- دستگاه یا محدوده شبکه تازه Step-up ایجاد می‌کند.

## بازیابی رمز

پاسخ درخواست برای حساب موجود و ناموجود یکسان است. Reset Token فقط ۱۵ دقیقه اعتبار دارد، به‌شکل HMAC ذخیره می‌شود و پس از مصرف تمام نشست‌های کاربر لغو می‌شوند. Adapter ارسال ایمیل باید در مرحله اتصال سرویس پیام، توکن را مستقیم تحویل دهد و حق ثبت آن در Log را ندارد.
