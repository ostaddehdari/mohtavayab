# سیاست Device و IP

Device ID یک شناسهٔ تصادفی مرورگر است، نه Fingerprint مخفی و نه عامل احراز هویت. سمت سرور فقط HMAC آن ذخیره می‌شود. User-Agent برای ساخت برچسب قابل‌فهم و سیگنال محدود ریسک استفاده و به‌شکل HMAC ثبت می‌شود.

IP خام نگهداری نمی‌شود. برای تشخیص تغییر شبکه، Prefix آدرس IPv4 در سطح `/24` و IPv6 در سطح `/64` محاسبه و سپس با Pepper به HMAC تبدیل می‌شود. این مقدار برای تعیین مکان دقیق یا پروفایل‌سازی قابل استفاده نیست.

## تصمیم ریسک

| سیگنال                                           | تصمیم                     |
| ------------------------------------------------ | ------------------------- |
| دستگاه و Prefix شناخته‌شده با MFA در ۳۰ روز اخیر | ادامه نشست                |
| دستگاه یا Prefix تازه                            | Step-up MFA               |
| Device ID متفاوت هنگام Refresh                   | لغو Token Family          |
| بیش از ۸ تلاش در ۱۵ دقیقه                        | Rate limit                |
| ده خطای رمز متوالی                               | قفل موقت ۱۵ دقیقه         |
| Refresh Token قبلی                               | تشخیص replay و لغو Family |

اعتماد به `X-Forwarded-For` فقط زمانی فعال می‌شود که `AUTH_TRUST_PROXY=true` و Nginx مورد اعتماد تنها Proxy جلوی API باشد.
