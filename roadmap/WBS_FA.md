# ساختار شکست کار (WBS) ـ هادی / mohtavayab

> منبع حقیقت ماشین‌خوان این سند `roadmap/roadmap.json` است. این فایل برای مرور انسانی تولید شده است.

## قواعد ثابت

- هر استیج ۴ ورک و هر ورک ۵ تسک دارد؛ بنابراین هر استیج دقیقاً ۲۰ تسک دارد.
- تسک نباید بیشتر از دو نفر-روز باشد. تسک بزرگ‌تر باید پیش از شروع شکسته شود.
- هیچ قابلیت بدون حالت‌های Loading، Empty، Partial، Failed، Permission denied و Needs action تکمیل نیست.
- Provider فقط بعد از Contract Test، تست رسانه واقعی و Kill Switch قابل فعال‌سازی است.
- تعریف Done شامل کد، تست، Migration، Telemetry، مستند، Runbook و دموی پذیرش است.
